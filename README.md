# 《被紀念的痕跡》 — 互動敘事與 UI 重構 (v5)

## 核心立意與五階段互動敘事流程 (UX Storyboard)

「人靠自己的努力留下的痕跡終會淡去（挫敗），但在神的眼中，你不需要再用力證明什麼，祂早已記念你的一切。」

1. **階段一：誤導與誘騙（開場）**
   - 點擊「開始體驗」後顯示手掌輪廓引導框，包裝為「力度測試」裝置。
   - 主標題：「留下你的痕跡」
   - 副標題：「這是一個關於你存在的測試。請將手掌貼近鏡頭，並**盡你所能，用力按壓**。」
2. **階段二：努力與挫敗（第一次按壓）**
   - 用力按壓時，石膏凹陷處浮現淡淡紅色痕跡，顯示：「再用力一點... 試圖留住它...」
   - 停止或時間到時，紅色消退、掌印變得很淺；多停留三秒後顯示：「無論多努力，靠自己力留下的痕跡，始終都會淡去...」
3. **階段三：視角切換（轉折）**
   - 畫面暗下並執行濾鏡過場動畫，解除「用力」限制。
   - 顯示：「但如果，換一個視角看呢？」／「請輕輕將手放在鏡頭前... 不需要再用力。」
4. **階段四：恩典與顯影（第二次輕輕擺放）**
   - 低閾值輕放即瞬間生成清晰、深刻、不閃爍的掌印，並停留 4 秒供安靜欣賞。
   - 顯示：「你在世上每一個微小的片段，都在衪心上留下永恆的印記。」
5. **階段五：啟示與結束**
   - 顯示：「你可以放手了。你不需要再用力證明什麼，因為你一直被看見。」
   - 底部彈出經文：「我未成形的體質，你的眼早已看見了；你所定的日子，我尚未度一日，都在你的冊子寫上了。（詩篇 139:16）」
   - 提供「觀看完整歷程回放」按鈕，以分割對比畫面與 3D 連續動畫重播「用力按壓」與「輕輕放下」的歷程。

## UI/UX 修正項目
- **標題層級統一**：全域 Header 統一為 `《被紀念的痕跡》`，移除舊版副標「被珍藏的印記」。
- **重播按鈕修正**：移除「觀看示範」中的「重播顯影」按鈕；於階段五新增「觀看完整歷程回放」。
- **示範模式防劇透**：「觀看示範」僅顯示「此為互動流程演示，請依畫面指示操作鏡頭。」，不劇透神視角或經文。
