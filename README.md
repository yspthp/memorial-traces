# 被紀念的痕跡 — 石膏掌印 v2

純前端 Three.js 互動體驗，部署於 GitHub Pages。

## 使用

- 首頁按「觀看示範」可在不開啟鏡頭的情況下查看凹陷掌印；`?demo=1` 自動開啟示範。
- 按「開始鏡頭體驗」，允許相機。請用深色、均勻背景，五指向上張開，讓完整指尖、拇指及掌根入鏡。
- 穩定停留三秒 → 淡痕 → 移開手掌 → 再次輕觸 → 清晰顯影。
- `?debug=1` 顯示狀態。鏡頭畫面、輪廓僅於頁面記憶體處理，不上傳或持久儲存；切換示範或離開頁面會關閉鏡頭。

## 實作

- `app.mjs`：可變形正面、側壁及完整背面；沒有會遮住凹陷的第二層實心正面。更新頂點後重新計算法線，配合陰影及暖白光。
- `relief.mjs`：保比例裁切、帶正負值的高度場、手形內部凹陷及少量邊緣擠起。
- `capture.mjs`：暗場亮度分割、完整入鏡／分指啟發式檢查，以及固定參考幀重疊檢查。選擇穩定輪廓，不再累積所有移動輪廓。
- `sw.js`：network-first；舊快取只清理本項目路徑。舊版本用戶可重新整理兩次或強制重新整理。
- 繼續使用項目原有的 `assets/vendor/three.module.js`，不用 CDN、後端或建置程序。原 GLB 保留但新版不載入。

## 限制與測試

此版本是藝術化掌印，不是照片級手部掃描。掌紋與掌丘深度是程序化模板，不是真實掌紋、壓力或深度量測。辨識使用暗場輪廓啟發式，不是訓練過的手部模型，現場光線與背景仍需測試調整。

執行 `node --test tests/relief.test.mjs`：空白輸入、凹陷深度與邊界、比例／置中、錯誤輪廓、移動重疊共五項測試。2026-09-17 本機全部通過；另以 Edge 無介面測試桌面／手機畫面、重播、鏡頭拒絕與恢復、人工影像的三秒停留／移開／再接觸／顯影及鏡頭關閉。未使用現場實體鏡頭。
