# 《被紀念的痕跡》 — 互動敘事與 UI 重構 (v5.2)

## 核心立意與五階段互動敘事流程 (UX Storyboard)

「人靠自己的努力留下的痕跡終會淡去（挫敗），但在神的眼中，你不需要再用力證明什麼，祂早已記念你的一切。」

1. **階段一：誤導與誘騙（開場）**
   - 點擊「開始體驗」後顯示手掌輪廓引導框，包裝為「力度測試」裝置。
   - 主標題：「留下你的痕跡」
   - 副標題：「這是一個關於你存在的測試。請將手掌放在亞克力膠板上，並**盡你所能，用力按壓**。」
2. **階段二：努力與挫敗（第一次按壓）**
   - 用力按壓時，石膏凹陷處浮現淡淡紅色痕跡，顯示：「再用力一點... 試圖留住它...」
   - 停止或時間到時，紅色消退、掌印變得很淺（搭配 3 秒徒勞消退關鍵影格動畫）；多停留三秒後顯示：「無論多努力，靠自己努力留下的痕跡，始終都會消去...」
3. **階段三：視角切換（轉折）**
   - 畫面執行 1.5 秒濾鏡切換（灰階轉暖彩與金色邊緣光暈泛入），解除「用力」限制。
   - 顯示：「但如果，換一個視角看呢？」／「請輕輕將手放在鏡頭前... 不需要再用力。」
4. **階段四：恩典與顯影（第二次輕輕擺放）**
   - 低閾值輕放即觸發顯影，手掌印以 5.5 秒（`>= 5000ms`）緩緩深刻浮現，文字於 1.8 秒後以 2.8 秒緩慢淡入，整體階段四停留 10 秒供安靜欣賞。
   - 顯示：「你在世上每一個微小的片段，都在衪心上留下永恆的印記。」
5. **階段五：啟示與結束**
   - 進入階段五後先留白 1.2 秒，再以 2.8 秒緩慢淡入：「你可以放手了。你不需要再用力證明什麼，因為你一直被看見。」
   - 鏡頭預覽框浮現發光邊框與打勾完成提示 Overlay（「印記已保存 · 你可以放手了」）。
   - 於階段五第 4.8 秒再以 2.8 秒緩慢淡入底部經文：「我未成形的體質，你的眼早已看見了；你所定的日子，我尚未度一日，都在你的冊子寫上了。（詩篇 139:16）」
   - 僅於階段五動態渲染「觀看完整歷程回放」按鈕，讀取並重播使用者剛才「用力按壓」與「輕輕放下」的關鍵截圖與 3D 掌印對比歷程。
6. **觀看示範模式**
   - 僅顯示：「此為互動流程演示，請依畫面指示操作鏡頭。」
